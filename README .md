# Character Manager — TP3 (Java Visual SIH-6406)

Character Manager adalah aplikasi konsol sederhana untuk membuat dan mengelola karakter game bertipe Warrior, Mage, Archer, dan Healer. HP dan attack dihitung otomatis dari level, dan setiap karakter memiliki atribut mana serta pengecekan status hidup.
